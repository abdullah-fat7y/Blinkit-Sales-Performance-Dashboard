# Blinkit Sales Performance Dashboard – Power BI

This project presents a comprehensive Power BI dashboard analyzing sales performance for **Blinkit – India’s Last Minute App**.  
The dashboard provides business insights into sales trends, outlet performance, product categories, and customer metrics.

---

## Project Overview

The dashboard is designed to help stakeholders:

- Monitor overall sales performance
- Analyze outlet-level performance
- Identify top-performing product categories
- Evaluate customer ratings and item visibility
- Support strategic retail decision-making

---

## Key KPIs

-  **Total Sales:** $1.20M  
-  **Average Sales:** $141  
-  **Number of Items:** 8,523  
-  **Average Rating:** 3.9  

---

##  Dashboard Features

### 1️ Sales Trend Analysis
- Year-wise outlet establishment sales trend
- Identifies growth patterns and peak sales periods

### 2️ Item Type Performance
- Sales breakdown by product categories
- Highlights top-performing segments (Fruits, Snacks, Household, Dairy, etc.)

### 3️ Fat Content Analysis
- Sales comparison between Low Fat and Regular products
- Tier-based outlet fat distribution analysis

### 4️ Outlet Size Analysis
- Sales distribution across Small, Medium, and High outlets

### 5️ Outlet Location Analysis
- Tier 1, Tier 2, and Tier 3 performance comparison

### 6️ Outlet Type Summary Table
Includes:
- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Item Visibility
- Conditional formatting for performance comparison
